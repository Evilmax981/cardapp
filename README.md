# cardapp
📇 CardApp
CardApp è un'applicazione Android semplice e funzionale progettata per facilitare l’accesso a moduli digitali e form di registrazione per gli uffici delle risorse umane di grandi aziende.
________________________________________
📱 Funzionalità principali
•	Schermata iniziale (MainActivity): mostra un logo tappabile che avvia l'app.
•	Seconda schermata (SecondActivity): consente di scegliere tra:
o	"Consulta tutte le CARD"
o	"Elenco moduli Form attivi"
Entrambe le opzioni portano alla schermata dei moduli.
•	Schermata moduli (PresenceActivity): offre accesso diretto a 5 diversi form online (Microsoft Forms) per:
o	Lavoratori
o	Studenti
o	Pazienti
o	Visitatori
o	Clienti

🛠️ Tecnologie utilizzate

________________________________________
🚀 Come eseguire il progetto
1.	Clona la repository o scarica il .zip.
2.	Apri il progetto in Android Studio.
3.	Sincronizza i file Gradle.
4.	Collega un dispositivo Android o avvia un emulatore.
5.	Esegui l'app cliccando su ▶️.
